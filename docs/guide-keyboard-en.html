NUSA KEYBOARD APP GUIDE

Step-by-step instructions for installing, activating, and typing regional characters with Nusa Keyboard.

Introduction

Need to type in regional languages such as Nias? With the Nusa Keyboard app, you can easily type specialized letters! Characters ö and ŵ are natively available on the keyboard layout. You can switch effortlessly between regional language and Indonesian layouts.

In addition, this keyboard features a dedicated top row with instant wiki markup shortcut buttons (bold, italics, headings, wikilinks, footnotes), making it an indispensable tool for active contributors on Wikipedia, Wiktionary, and Wikibooks.

Installing and Configuring Nusa Keyboard

  1. Click the Google Play badge below to visit the Google Play Store:
  2. Locate the Nusa Keyboard app and tap "Install". Wait until the download finishes and the blue "Open" button is displayed.
    Nusa Keyboard installation completed
  3. Launch the app directly by tapping OPEN or navigate to your device's app drawer and tap the Nusa Keyboard icon.
    Nusa Keyboard icon in app drawer
  4. You will be presented with the Keyboard Setup screen. Tap the ACTIVATE KEYBOARD button.
    Nusa Keyboard Settings screen
  5. Your device's system keyboard list will appear. Toggle the switch to enable Nusa Keyboard.
    Nusa Keyboard enabled in system settings
  6. Finished! Nusa Keyboard is now active and ready for use.

Using Nusa Keyboard

  1. Launch any text editing or browsing app, such as WikiNusa.
  2. Tap on the search bar or text input field. Your system will show the currently active keyboard. Tap the Keyboard Switcher icon (usually on the bottom right navigation bar or in the notification pull-down menu).
    Tap the keyboard switcher icon
  3. Select Nusa Keyboard from the input method list.
    Selecting Nusa Keyboard
  4. You are now ready to type special characters like ö and ŵ with ease.
    Nusa Keyboard layout
  5. Tap the Globe icon on the bottom row of Nusa Keyboard to quickly toggle between regional language layout and standard Indonesian layout.
