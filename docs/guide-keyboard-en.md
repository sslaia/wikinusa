# NUSA KEYBOARD APPLICATION GUIDE

## INTRO

Need to type in regional languages such as Nias? With the Nusa Keyboard app, you can easily type specialized letters! **Characters ö and ŵ are natively available**. You can switch seamlessly between **regional language and Indonesian layouts**.

Furthermore, this keyboard includes **dedicated buttons for wiki markup codes**. It is an essential companion for active contributors to Wikipedia, Wiktionary, and Wikibooks.

## INSTALLING AND CONFIGURING NUSA KEYBOARD

1. Click on <a href="https://play.google.com/store/apps/details?id=io.github.sslaia.nusakeyboard"><img alt="Get it on Google Play" src="https://play.google.com/intl/en_us/badges/images/apps/en-play-badge.png" height="80pt"/></a> to visit the Google Play Store.

2. Locate the Nusa Keyboard app. Tap "Install". Wait until installation completes and the blue "Open" button appears.
![Nusa Keyboard installed](images/nusa-keyboard.webp)

3. Tap OPEN directly or locate the Nusa Keyboard icon in your device's app drawer.
![Nusa Keyboard in app drawer](images/laci-aplikasi.webp)

4. On the setup screen, tap the ACTIVATE KEYBOARD button.
![Nusa Keyboard Settings](images/nk-pengaturan.webp)

5. Toggle the switch to enable Nusa Keyboard in your Android system input settings.
![Nusa Keyboard Enabled](images/nk-aktif.webp)

6. Finished! You are ready to type with Nusa Keyboard.

## USING NUSA KEYBOARD

1. Launch any writing or reading app, such as WikiNusa.

2. Tap on any search bar or text field. Tap the keyboard switcher icon (usually at the bottom right of the navigation bar or in the notifications shade).
![Tap keyboard switcher](images/nk-tukar-papan-ketik.webp)

3. Select Nusa Keyboard.
![Selecting Nusa Keyboard](images/nk-terpilih.webp)

4. You are ready to type in regional languages with special characters like ö and ŵ.
![Nusa Keyboard layout](images/nk-nusa-keyboard.webp)

5. Tap the globe icon on the bottom row to quickly alternate between regional and Indonesian keyboard layouts.
